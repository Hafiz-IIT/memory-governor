# Project status

## Implemented

- SQLite-backed persistent memory
- scope-aware retrieval
- provenance and sensitivity labels
- TTL/expiry handling
- explicit forgetting and superseding
- transparent poisoning-pattern screening
- auditable write/retrieve/forget events
- Deterministic unit tests.
- GitHub Actions unit-test workflow.
- Reproducible example fixture.
- Architecture and research documentation.

## Research-stage / not claimed

- encrypted storage or secrets management
- formal privacy guarantees
- production prompt-injection detection
- semantic/vector retrieval
- real multi-user access-control deployment

## Claims boundary

The prototype does not provide encryption, semantic vector retrieval, production authentication, formal privacy guarantees, or a complete prompt-injection defense.

## Version

Public prototype line: **0.1.x**.
