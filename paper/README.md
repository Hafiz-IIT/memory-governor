# Paper Track — Memory Governance

## Working title
**Memory Governance for AI Agents: Provenance, Retention and Explicit Forgetting**

## Current status
Research prototype / paper preparation.

## Contribution hypothesis
Study whether persistent agent memory should be governed by provenance, sensitivity, retention age and explicit forgetting rules rather than treated as an undifferentiated retrieval store.

## Required before submission
- benchmark corpus
- retention-policy baselines
- privacy/security failure cases
- retrieval-quality and deletion-compliance metrics
- adversarial tests
- reproducibility package
- prior-art audit

No publication claim is made at this stage.
